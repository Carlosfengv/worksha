# 草稿目录授权独立恢复（宿主接口）

本接口供应用自己的恢复界面使用，不提供给 guest，不新增插件网络权限。
原 96 个 IPC、此前 122 个总命令、Provider 请求 / 回执、来源选择和旧恢复信封保持。
新增 `perform_provider_draft_recovery(input)`，严格 schema / TypeScript 位于
`contracts/domain/provider-draft-recovery/`；SDK 导出命令为
`schemas-provider-draft-recovery`。

## 接口

| 操作      | 输入                                | 结果与边界                                                                                          |
| --------- | ----------------------------------- | --------------------------------------------------------------------------------------------------- |
| `list`    | 当前 `storeId`                      | 单次有界元数据列表，不批量读取 SQL 原结果或解码请求正文；原结果标记为 `unchecked`，不能直接结束引用 |
| `inspect` | 宿主原 `owner`（storeId / ownerId） | 逐条核查原归属、规范请求摘要和实际 SQL 结果；返回原请求用于原查询 / 取消接口，不提交、不续权        |
| `finish`  | 同一原 `owner`                      | 再次证明终态与引用边界；返回 `released`，未证明时保持原记录和授权                                   |

三个操作都不接受调用方指定的路径、请求、selection、force、Key 或新的 operationId。
错误数据库拒绝。核查不调用 guest / worker、Vault、模型目录或模型；查询不改变
Provider SQL 序号。`finish` 仅复用原来源终态 bookkeeping 和精确引用回收，
不删除 Provider、凭据或原 SQL 回执。

`pending / not-found / unavailable` 分别表示原操作在途、未查到和暂不可核查。
不能把没有 SQL 结果解释为未执行。`unattached` 仍须逐条核查后明确结束；
可能存在仍打开的编辑器，其后需要重新核查或授权。

## 原请求持久化与中断

原 `draft-catalog-owners` 版本 1 小记录、32 KiB / 128 条预算保持。
另增私有 `plugins/draft-catalog-requests`，目录 0700、文件 0600，版本 1，
每条最多 2 MiB、最多 128 条。只保存原 SourceRequest（含 Provider 配置及凭据引用），
不保存明文 Key、提示词或模型输出。请求内容不可变，先持久化完整副本，再落旧小索引。
副本写入失败时不发送业务提交。

如果中断发生在副本已写入、小索引未写入之间，逐条核查从验证后的副本恢复原摘要，
不改写旧小记录，也不能将它视为空闲引用并删除授权。原结果缺失时返回验证过的原输入，
用户可明确调用原 `cancel_provider_operation(request)`；保持同一编号和完整输入。
确认原取消回执后才可结束归属。此恢复入口不提供重试或重新提交连接。

旧版仅有哈希的小记录继续可读。SQL 结果存在时直接恢复原结果；若 SQL 和完整请求
副本均缺失，保持未知，不补造取消输入或权限。副本损坏、未来版本、范围 / 摘要不匹配、
权限不安全时拒绝核查和收尾并保留原字节，列表仍只显示待核查的元数据。

归属小记录丢失而请求副本仍在时，可以单独发现、逐条核查和取消同一个原操作。
但请求不能证明授权的创建 / 共享归属，确认终态后只移除该请求副本，不自动删除目录权限；
用户需到原插件管理入口核查并明确解除。共享 / 借用引用、替换后的 nonce 和相关在途操作
继续受原回收规则保护。重启不续期授权，独立恢复不要求插件仍启用。

## 界面与本机提示

服务商恢复区域提供“草稿目录授权恢复”，显式读取宿主元数据后逐条核查。
原始请求只用于原取消接口，不渲染凭据引用；界面不显示明文请求正文。
确认结束时宿主重新核查，界面只移除同一条、未变化的本机授权提示。
本机存储不可读或损坏不阻塞宿主核查 / 收尾；原 Provider 恢复信封保持。

本机授权提示有独立人工移除入口，需确认且比较打开时的原字节。
它不会取消操作、结束宿主归属或解除权限，不推定未知提示的数据库。
扫描限制条数和累计展示预算，首条超量提示作为单独待核查快照保留，剩余提示不删除。
关闭、重连、切换原数据库或刷新核查均使旧结果和确认失效，迟到回复不能发布到新视图。

## 恢复边界

此接口只提供原始请求的独立核查与恢复，不提供全自动回收或整机数据丢失恢复。旧版本数据的升级与回退需按实际格式单独核对。
