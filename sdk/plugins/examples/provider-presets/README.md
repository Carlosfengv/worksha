# 供应商静态预设

这是无需 WASM 的声明式包，提供两种基础协议的初始值。示例地址使用 `.invalid`，请在自己的受管环境替换。

用随包 `local-agent-service --plugin-sdk keygen <key>` 生成测试发布者密钥，再运行 `--plugin-sdk pack <package目录> <输出.laplug> <key>`。在原生插件页检查签名、批准发布者、安装并启用，然后在 Providers → 连接与调用 → 添加供应商中搜索“预设示例”。选择只填草稿，Key、模型读取、保存和验证沿用现有流程。

静态预设不授予连接、模型目录或推理权限。包没有网络 broker 权限，也没有程序执行能力。插件页原“创建本机连接”入口保留旧幂等行为；统一添加入口提供可编辑草稿。接口、来源身份与失效边界见 [宿主预设契约](../../docs/provider-presets.md)。
