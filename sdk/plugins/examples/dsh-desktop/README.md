# 接入 DeepSeek Harness 桌面端

本例包含 DSH 侧的只读桥接包和 Local Agent 侧的签名来源包。DSH 侧锁定桌面端 `0.2.2-rc.1`，由 DSH 自己加载。它使用官方 Session Controller 的 `list` 和 `events`，不读取内部文件或凭据，不创建、恢复、驱动 Agent 或调用模型。

1. 按 [DSH 桥接包说明](bridge/README.md) 安装并启用 `bridge`。DSH 开始发布 `~/.local/share/local-agent/dsh-desktop/facts.jsonl`。需要重启时，正常退出并重新打开 DSH，保留原会话。
2. 运行 `pnpm prepare:plugins`，按 [SDK](../../README.md) 签名并打包本目录的 `package`，在 Local Agent 插件中心上传、检查发布者并启用。
3. 在插件详情选择桥接输出的 JSONL，核对定期读取提示。初次发布后确认“统一会话展示”。随后在总览、Agents、Sessions、请求和项目中查看数据，无须修改这些页面的代码或为各页重复授权。
4. 可另行安装 [`source-report`](../source-report/package/contributions.json) 样例。启用后从左侧打开报表，授权调用指定会话来源，再手动读取汇总。

桥接每 5 秒发布一个完整的快照，使用首尾代次和记录数校验防止半写覆盖旧数据。目录和文件限当前用户访问。会话历史只读取最近 40 条消息窗口；旧格式、缺失历史或读取失败的会话保留目录元数据，正文和未取得的用量保持未知。运行状态来自 DSH 的快照；超过 20 秒未发布后活动过期，原有历史保留。报告响应、宿主请求与实时采样保持各自口径。

`source.refreshSeconds` 只适用于显式声明 `host.source-watch@1` 的完整来源包，范围 5 到 300 秒；`maxAgeSeconds` 可选，至少是读取间隔的两倍，最多 900 秒。启用实时观测时，文件必须包含带记录数的快照开头和同代的提交结尾。完整发布可以标记历史覆盖不全；写入中断的文件不能覆盖上一次数据。读取同一用户选定文件并持续核对身份。停止统一展示、撤销文件授权和停用插件是不同操作；停用或撤销文件授权后停止读取。重新打开 Local Agent 后按来源授权流程恢复。卸载 DSH 桥接包可停止发布，原 DSH 会话及导出文件保留。

在插件中心的「Agent 接入」管理此插件。声明的 Agent 产品进入统一列表，会话、响应、活动和项目根据各自的能力声明自动展示。会话桥接提供只读观测。1.1 版来源包可通过独立的[模型连接桥接](connection-bridge/README.md)在 Agent 详情中切换新会话的默认模型。

统一展示授权生效后，宿主在限额内仅于内存保留最近一次已验证的完整文件快照，保证会话正文和列表来自同一版本。下一次成功读取替换旧快照；停用或撤销授权即清除读取权限及相应的内存快照，正文不写入应用数据库。
