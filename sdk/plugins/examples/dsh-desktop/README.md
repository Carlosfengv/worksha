# 接入 DeepSeek Harness 桌面端

本例包含 DSH 侧的只读桥接包和 Local Agent 侧的签名来源包。DSH 侧锁定桌面端 `0.2.2-rc.1`，由 DSH 自己加载。它使用官方 Session Controller 的 `list` 和 `events`，不读取内部文件或凭据，不创建、恢复、驱动 Agent 或调用模型。

1. 在 Local Agent 的插件中心打开「Agent 接入」，选择「安装随附 DSH」，核对发布者与权限后确认安装会话来源。模型连接可直接从 Agents 列表切换，首次使用需启用模型连接桥接。
2. 选择「打开 DSH 桥接文件夹」，按随附的 [DSH 桥接包说明](bridge/README.md) 在 DSH 安装并启用 `bridge`。DSH 开始发布 `~/.local/share/local-agent/dsh-desktop/facts.jsonl`。需要重启时，正常退出并重新打开 DSH，保留原会话。
3. 在「连接与观测」选择桥接输出的 JSONL，核对定期读取提示。初次发布后确认「统一会话展示」。随后在 Agent 概览、Sessions、调用、项目和 MCP 中查看数据，无须为各页重复授权。
4. 可另行安装 [`source-report`](../source-report/package/contributions.json) 样例。启用后从左侧打开报表，授权调用指定会话来源，再手动读取汇总。

桥接随会话状态和用户消息变化发布快照，并每 5 秒更新一次。首尾代次和记录数用于校验完整性。目录和文件限当前用户访问。会话历史只读取最近 40 条消息窗口。旧格式、缺失历史或读取失败的会话保留目录元数据。首页显示最近一条用户消息与其发起时间，运行状态由 DSH 报告。超过 20 秒未发布后活动过期，原有历史保留。

更新到 1.3 版只读桥接及支持该版本的 Worksha 后，首页可显示 DSH 直连任务的本轮耗时、TTFT、已上报的生成均速和输出 Token 数。耗时以用户消息的时间为起点，完成后以记录到的同轮结束时间为准。现有已授权的导出文件可以继续使用。

`source.refreshSeconds` 适用于声明 `host.source-watch@1` 的完整来源包，范围 5 到 300 秒。`maxAgeSeconds` 至少是声明间隔的两倍，最多 900 秒。Worksha 每秒检查 DSH 的已授权文件，在文件更新时读取完整快照。首次确认统一展示后，Worksha 会在重开时验证并恢复同一文件的授权。更换文件、停止统一展示、撤销读取、停用来源或撤销发布者信任后，需要重新确认相应权限。卸载 DSH 桥接包可停止发布，原会话及导出文件保留。

在插件中心的「Agent 接入」管理此插件。声明的 Agent 产品进入统一列表，会话、响应、活动和项目根据各自的能力声明自动展示。会话桥接提供只读观测。查看 MCP 执行需要 1.2 版来源包和 1.1 版只读桥接。1.1 及后续版本的来源包可通过独立的[模型连接桥接](connection-bridge/README.md)在 Agent 详情中切换新会话的默认模型。

统一展示授权生效后，宿主在限额内仅于内存保留最近一次已验证的完整文件快照，保证会话正文和列表来自同一版本。下一次成功读取替换旧快照；停用或撤销授权即清除读取权限及相应的内存快照，正文不写入应用数据库。

## 更新随包来源

修改来源清单或 Wasm 实现后，运行 `pnpm prepare:plugins`，按 [SDK 签名步骤](../../README.md#构建与打包)用随包来源的同一发布者密钥生成新的签名包，校验后更新 `src-tauri/resources/dsh-desktop.laplug`。签名私钥保存在源码和 App 包之外。随 App 提供的桥接目录直接来自本示例。
