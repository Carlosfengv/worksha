# 插件原生验收

交付与交互验收使用打包的 Tauri 窗口。浏览器夹具辅助检查异步与布局，不替代系统选包、键盘、滚动和弹层验证。

## 隔离

开始前记录用户正在运行的 App / service 路径和 PID。测试使用合成来源、独立 `LOCAL_AGENT_SOURCE_HOME` / `LOCAL_AGENT_DATA_DIR` 和独立编译的应用身份，启动 PATH 仅含系统目录。不能连接、退出或改写用户原实例。

只修改 Info.plist 不能替代编译期单实例身份隔离。等待就绪时核对本次子进程仍存活，服务来自所选测试包；不将其他实例的运行记录当作本次启动成功。临时路径先解析为真实路径，避免 macOS 的 `/var` 别名触发符号链接保护。

## 流程

1. 通过系统文件面板验证取消、篡改包拒绝、签名信任选择及有效包安装。安装后单独启用与授权；认证 API 准备包不等于原生选包通过。
2. 检查 Agent / Provider / 账户及对象详情的只读卡片、页签、方向键、焦点与深链，保留原页面选择；账户未知时不猜归属。
3. 页面打开时改变依赖启停、版本或发布者信任，等待轮询显示降级与恢复。记录操作方式，不以重开页面代替原页更新验证。
4. 核对消费者启用、自身授权版本、activation epoch 和快照时间。恢复不自动采集或执行工具；过期仍显示过期，直接查询受影响视图也受授权限制。
5. 使用实际滚轮检查正文、列表与详情的滚动归属；通过 Tab / Space / Enter 检查选择、安装、关闭与返回。正常退出并重开，核对持久状态与待刷新状态。
6. 检查移除当前深链插件后的键盘返回，以及窗口调整后长标题、依赖标识和页签的可见焦点。

## 窗口与证据

最小尺寸以 `tauri.conf.json` 为准，当前为 720×560。分别记录精确尺寸启动和实际拖拽钳制：启动在最小尺寸不证明拖拽边界通过。拖拽需先放大，再向低于下限的方向收缩，同时保存实际起终尺寸。截图像素与 CSS 尺寸按设备缩放区分，坐标不得跨机器复用。

长文本夹具必须满足 SDK 和签名契约的长度限制，检查换行、完整可访问名称及所选页签内容。浏览器额外窄屏回归不计为原生窗口通过。工具未命中或尺寸未改变时如实记录，不修改生产窗口配置消除验收失败。

结束前核对源文件摘要、核心统计、Provider / 设置 / 来源授权和数据库完整性；保存主程序与服务摘要、签名和 entitlements。测试进程正常退出后按 [App 回收流程](test-app-cleanup.md) 清理本次确切路径并保存报告，确认原用户实例仍运行。

逐项区分本次结果、历史基线与未验证范围。离线、MemoryVault 和开发签名不能代替真实 Keychain、真实客户端调用或正式公证。
