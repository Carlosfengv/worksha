# Zeron 组件使用约定

使用锁定的 `zeron-ui@0.2.0-beta.19`、React 19、Tailwind CSS 4，以及 `components.json` 中的实际消费者别名。组件 API 以安装源码和类型为准。

## 安装与管理

新增组件前查看官方目录，运行 `view` 与 `add --dry-run`，核对依赖、公开属性和文件冲突，再通过官方 CLI 安装。`.zeron/install-state.json` 记录安装来源和文件摘要；`pnpm check:ui` 验证文件完整性与业务样式。

`src/components/ui/`、安装记录内的共享 hooks / lib 和 `src/styles/globals.css` 为受管理区域。不得直接修改内部样式、复制基础组件绕过限制，或刷新哈希消除检查失败。当前 CLI 没有卸载命令，未引用的安装依赖仍保持官方安装闭包；后续精简需先采用受支持的管理流程。

## 组合与布局

一个应用区域使用一套 AppShell，遵守布局直接子级关系。页面组合位于业务层；长页面正文自行滚动，DataTable 内部负责表格滚动。读屏状态的绝对定位需有局部相对定位边界，避免撑大外壳。

图文按钮使用公开图标参数；业务弹层、选择器和 Portal 通过公开 API 配置。表格单元格内的操作需在业务边界处理事件，避免触发行导航。大候选模型集合使用 Combobox。

| 场景                           | 组件与边界                                       |
| ------------------------------ | ------------------------------------------------ |
| 可筛选、排序、分页或激活的记录 | 官方 DataTable 与 ColumnHeader                   |
| 静态对账矩阵                   | Table                                            |
| 完整本地集合                   | 使用全量集合排序 / 分页                          |
| 后端游标页                     | 后端负责全量排序、筛选和页码，不将当前页当成全量 |
| 有限固定枚举                   | Select                                           |
| 大模型目录与搜索候选           | Combobox                                         |

## 样式与信息

业务样式使用 Zeron 的语义颜色、字体、surface、状态与焦点变量；间距和圆角使用 Tailwind 原生尺度。不要新增第二套颜色或控件尺寸系统，不使用硬编码颜色、内部选择器或 `!important` 覆盖组件。

图表通过公开属性使用语义分类色。实时模型配色按明确模型身份持久分配；品牌图标使用随包静态资源，未知系列保留通用图标，不根据连接名称猜品牌。第三方图标许可随应用分发。

展示层保留加载、错误、未知、部分覆盖、过期、未授权与确认无数据；缺失来源不能显示为已验证或零。图表不补造历史点，账户估算只在币种、覆盖和有效期均满足要求时显示。
