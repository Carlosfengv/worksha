# 业务功能、界面与操作对照

一级业务插件采用完整功能粒度。下面是当前已注册页面实际提供的功能，操作会受插件状态、任务阶段、连接、数据和授权条件限制。系统业务插件已接入依赖图、启停与卸载；界面与后台同时检查状态，不能以隐藏页面冒充停用。细粒度领域接口与外部 SDK 的完整迁移不计作已经完成。

此表由应用注册入口和 `system-features.ts` 定义生成；MCP 当前为配置与调用观测，不宣称可在该页面启动服务或执行工具。

| 功能 | 页面入口 | 现有操作 | 使用条件 |
| --- | --- | --- | --- |
| 总览 | `#/overview` | 管理 Agents；查看会话；筛选统计来源与时间范围 | 活动、Token 速度、费用等以实际来源和采样能力为准；没有观测数据不能认作已验证空闲。 |
| Agents | `#/agents` | 切换模型连接；读取本机会话；连接与观测 | 发现客户端不等于连接或授权成功；原生会话读取和模型连接分别配置。 |
| 任务 | `#/tasks` | 新建任务；连接设置；发送；停止本轮 | 需要可用的 Agent 连接和用户确认的项目目录。具体执行、审批及停止能力以所选 Agent 支持范围为准；读取 Codex 会话不等于已接入任务控制。 |
| 项目 | `#/projects` | 查看项目；Sessions；修改记录；端口与服务；磁盘与 Git | 项目来自已授权会话目录。Git、文件与端口信息还取决于本机目录和读取权限；缺失信息保持未知。 |
| Providers | `#/providers` | 添加供应商；配置凭据与模型；查看账户与额度 | API 连接需要实际配置与验证；官方订阅与 API 额度不混为一项。具体数据以来源支持和授权范围为准。 |
| 模型服务 | `#/model-services` | 创建模型服务；编辑服务成员与路由策略；删除服务 | 需要先配置 Provider 和可用模型；发布与切换以实际结果为准。 |
| MCP | `#/mcp` | 配置来源与历史关联；筛选 MCP 调用；查看调用详情；MCP 调用比较 | 当前页面用于配置与调用观测，不提供服务启动或工具执行。配置声明和实际调用记录分别展示，缺失状态保持未知。 |
| Sessions | `#/sessions` | 搜索会话；重新检查来源；对话；调用时间线；上下文；费用；磁盘与项目 | 需要读取对应原生来源或授权上传插件的数据；未提供的时序、费用与客户端归属保持未知。 |
| 请求 | `#/requests` | 筛选请求；打开请求详情；导出记录 | 可见范围取决于实际采集和内容设置；未经观测入口的调用可能缺少指标，不代表完整调用量。 |

设置、授权和插件中心是常驻宿主入口；业务插件停用不能关闭恢复与授权撤销能力。身份、Agent 运行适配、细粒度页面贡献和外部 SDK 的其余迁移继续按既定阶段实施，既定需求不因当前功能说明而缩减。
